# Volvo Trucks Website

Open the project using a live server, preferably starting from  
[`volvo_trucks/main/index.html`](volvo_trucks/main/index.html).

---

### About
This website was created for a **school project** and is a very **amateur/learning exercise**.  
It’s not an official Volvo product and is meant only for educational purposes.

---

### How to Run
1. Clone or download this repository.
2. Open the folder in your editor (e.g. VS Code).
3. Start a **Live Server** (or simply open `main/index.html` in your browser).
